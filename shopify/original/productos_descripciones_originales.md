# Descripciones originales de productos (respaldo, 2026-09-26)

Estas eran las descripciones publicadas antes del rediseño. Varias contenían notas internas de negocio
(visibles para clientes) y HTML escapado (`&lt;p&gt;`), por eso se reemplazaron.

- **Soporte Lumbar Ajustable** — Cojín lumbar con correa ajustable y rango de compresión publicado, no genérico. Se adapta a la curva baja de la espalda para reducir la carga en sesiones largas sentado. / Parte del Kit Setup Correcto — funciona junto al reposapiés ergonómico para corregir la postura de oficina desde la base.
- **Reposapiés Ergonómico Inclinable** — Reposapiés con inclinación ajustable para mejorar la circulación y reducir la tensión en piernas y espalda baja durante jornadas largas sentado. / Complementa al soporte lumbar — juntos forman el Kit Setup Correcto.
- **Soporte para Laptop con Brazo Ajustable** — Brazo articulado que sube el notebook a la altura correcta de los ojos, liberando espacio de escritorio y reduciendo la tensión de cuello por mirar hacia abajo. / El upsell natural para quien ya resolvió su postura de silla con el Kit Setup Correcto.
- **Cojín de Asiento Anatómico** — Cojín de memory foam con corte anatómico que distribuye el peso y reduce la presión en isquiones y coxis en jornadas sentado. / Se degrada con el uso normal — pensado como recompra a mediano plazo, no de una sola vez.
- **Lámpara de Escritorio LED Regulable** — Luz LED con temperatura de color regulable para reducir la fatiga visual en jornadas frente a la pantalla, sin parpadeo ni deslumbre. / Complemento de escritorio pensado para subir el ticket promedio sin sacrificar utilidad real.
- **Organizador de Cables + Mini Regleta** — Sistema de orden para cables y una mini regleta de escritorio, diseño propio para dejar el setup limpio y sin enredos. / Ticket bajo, ideal para sumar al carrito junto al Kit Setup Correcto.
- **Corrector de Postura Ajustable** — Banda ajustable que recuerda a los hombros mantener una postura neutra durante el día. Producto de entrada, pensado con contenido educativo sobre cuándo realmente sirve un corrector y cuándo no. / Ideal como primera compra de bajo riesgo antes de pasar al Kit Setup Correcto o a la pistola de masaje.
- **Pistola de Masaje EJE** — Pistola de masaje de percusión gama media, con protocolo de uso por deporte avalado por kinesiólogo — no solo el aparato, sino cómo y cuándo usarlo bien. / El hero de recuperación de EJE: el único producto con motor del catálogo, con control de calidad reforzado.
- **Rodillo de Espuma Texturizado** — Rodillo de espuma con textura para liberación miofascial profunda antes o después de entrenar. Categoría de alta rotación y bajo riesgo, pensada para uso diario.
- **Set de Bandas de Resistencia y Movilidad** — Set de bandas elásticas de distinta resistencia para movilidad, activación y trabajo de piernas. Alta rotación, bajo riesgo de devolución.
- **Bola de Liberación Miofascial Doble** — Bola doble tipo "peanut" para liberar tensión en cuello, espalda y glúteos con precisión que un rodillo no logra. Ticket bajo, ideal para subir el carrito en checkout.
- **Banda de Compresión para Piernas** — Manga de compresión textil para piernas que ayuda a la recuperación post-entreno favoreciendo la circulación. Guía de talla incluida para minimizar devoluciones.
- **Cinta de Estiramiento con Guía de Posiciones** — Correa de estiramiento con guía impresa de posiciones — el vehículo físico del contenido educativo de EJE, no solo un elástico.
- **Spray de Magnesio Tópico Post-Entreno** — Spray de magnesio de uso tópico (no oral) para aplicar después de entrenar. El único consumible del catálogo — pensado desde el día uno como motor de recompra, no de primera compra.
- **Kit Setup Correcto** — El soporte lumbar ajustable y el reposapiés ergonómico, empaquetados juntos con una guía de medición impresa para armar tu setup de oficina bien desde el primer día. / Es el producto que preventamos primero: la recomendación segura y universal cuando el diagnóstico no aísla una zona específica.
- **Kit Escritorio Completo** — El soporte para laptop con brazo ajustable, el cojín de asiento anatómico y el organizador de cables + mini regleta, empaquetados juntos para dejar tu escritorio ordenado y tu postura corregida en una sola compra. / Son las tres piezas que más rápido cambian cómo se siente trabajar sentado: altura de pantalla correcta, soporte lumbar-pélvico en el asiento, y un cable menos con el que tropezar. Pensado para quien recién está armando su setup de oficina o teletrabajo desde cero.
- **Kit Recuperación Post-Entreno** — El rodillo de espuma texturizado, el set de bandas de resistencia y movilidad, y el spray de magnesio tópico, juntos en una rutina de recuperación completa para después de entrenar. / El rodillo y las bandas trabajan la liberación miofascial y la movilidad articular, mientras el magnesio ayuda a relajar el músculo antes de dormir. Es el kit pensado para quien entrena con regularidad y quiere recuperarse mejor entre sesiones, no solo estirar.
- **Kit Postura + Movilidad** — El corrector de postura ajustable y la cinta de estiramiento con guía de posiciones, empaquetados juntos para trabajar la postura desde dos frentes: sostén activo durante el día y movilidad guiada para compensar horas sentado. / El corrector recuerda a los hombros y la espalda alta mantener una alineación correcta, y la cinta de estiramiento facilita rutinas cortas de movilidad con posiciones marcadas, sin necesidad de un instructor. Ideal como complemento del Kit Setup Correcto o para quien ya tiene resuelto el escritorio y quiere trabajar el cuerpo directamente.
